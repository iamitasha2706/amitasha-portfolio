# Images

Put your photos here. The site currently expects these files (used in the About "Beyond the work" strip):

- `mountains-1.jpg` — Suraj Taal lake
- `mountains-2.jpg` — hillside garden / dog
- `mountains-3.jpg` — valley village view
- `mountains-4.jpg` — snow
- `mountains-5.jpg` — rainbow over mountains

Optional (wire up in `src/data/portfolio.ts`):

- Your headshot for the hero — set `headshot.src = '/images/me.jpg'`.
- Community photos — add to `community.photos`.

Reference any image from code as `/images/<filename>` (the `public/` folder is served at the site root).
Keep files reasonably sized (ideally under ~500 KB each) so the page loads fast.
